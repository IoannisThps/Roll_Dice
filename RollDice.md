# 🎲 ASCII Dice Roller

This is a simple Python terminal application that simulates rolling a six-sided die using ASCII art.

## Features

- Generates a random number between 1 and 6.
- Displays a visual representation of the die using ASCII characters.
- Allows the user to roll again or exit the program.

## How It Works

When the program runs:

1. It rolls a virtual die (random number between 1 and 6).
2. Prints the corresponding die face using ASCII art.
3. Asks the user if they want to roll again.
4. Repeats the process if the user enters `y`.
